# bulario-work

Pasta de trabalho da reescrita do bulário (branch `bulario-lotes`, nunca entra na `main`).
Contém textos recortados de bulas profissionais públicas (ANVISA/fabricantes), a versão
publicada de cada medicamento para comparação, a especificação (`ESPEC.md`) e o conferidor
de doses. As saídas ficam em `loteN_out/` e são revisadas antes de irem para o Notion.
